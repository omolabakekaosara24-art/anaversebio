# ANAVERSE CBT

Welcome to Anaverse CBT — practice smarter, score higher.

**Motto:** Learn, grow, succeed

Biology paper: **Characteristics of Living Organisms** — 40 questions, **15 minutes**.

## Student flow

1. Open the site
2. Student entrance → full name + Gmail
3. Sit the paper once (one attempt per account / device)
4. See **your** score only

## Tutor flow

1. Same sign-in
2. Open **Tutor desk**
3. Enter tutor code: `Biohubabundance`
4. See the class board (all scores)

## Deploy (free website)

This is a full web app (not a static page). Host it on [Vercel](https://vercel.com):

1. Sign in to Vercel with GitHub
2. **Add New Project** → import this repository
3. Deploy

You get a public link such as `https://anaversebio.vercel.app`.

Students open that link in any browser — **no Grok account required**.
